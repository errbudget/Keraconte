# Décisions d'architecture (ADR)

Chaque décision structurante est consignée ici : le contexte qui l'impose,
les options pesées — mesures à l'appui quand elles existent — et ce qui en
découle. Une ADR ne décrit pas le code : elle fixe ce qu'on a décidé, et
surtout pourquoi, pour qu'on puisse y revenir sans réexcaver les mesures.

Statuts : **Proposé** (en discussion), **Accepté** (fait foi), **Remplacé
par N** (l'ADR N prend le relais), **Refusé** (gardé pour mémoire des
raisons).
